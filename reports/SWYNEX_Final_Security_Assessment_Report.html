3. Granular Assessment Findings & Remediations

SEC-01: Broken Access Control on Admin Dashboard API
CVSS 8.2 (High)

Target: Orphanage Management System (/api/admin/dashboard)

During unauthenticated testing, direct GET requests dispatched to the administrative dashboard API endpoint returned an HTTP 200 OK status alongside private operational telemetry without requiring an Authorization Bearer header.

Remediation: Implemented a server-side route decorator enforcing administrative role verification:

@app.route('/api/admin/dashboard', methods=['GET'])
@role_required("ADMIN")
def get_dashboard_metrics():
    # Validates Bearer JWT signature & role claim
    return jsonify(calculate_metrics()), 200

Verification: Post-deployment retesting rejected unauthenticated requests with HTTP 401: {"message": "Authorization header missing"}.

WEB-03: SQL Injection — Administrative Authentication Bypass
CVSS 8.6 (High)

Target: OWASP Juice Shop (/rest/user/login)

Submitting the payload ' OR 1=1-- into the email input field dynamically altered the backend SQL statement, bypassing password authentication entirely. The application immediately issued an administrator session token and unlocked the "Login Admin" challenge.

Remediation: Replaced dynamic query concatenation with parameterized prepared statements and ORM abstraction.

WEB-01 & SEC-02: Missing Defense-in-Depth HTTP Security Headers
CVSS 5.4 (Medium)

Target: Web Application HTTP Response Headers

Response header analysis demonstrated the absence of Content-Security-Policy (CSP) and Strict-Transport-Security (HSTS), compounded by wildcard CORS (Access-Control-Allow-Origin: *).

Remediation: Configured standardized reverse-proxy headers enforcing HTTPS-only transport, MIME-type sniffing suppression, and strict script source policies.

NET-01 & NET-02: Transport Layer Protocol & Cryptographic Integrity
Verified Secure

Target: Workstation Wireshark Traffic Capture

Packet inspection confirmed the complete absence of plaintext HTTP communication (0 packets on port 80). Modern TLS 1.3 cryptographic handshakes were validated, featuring strong cipher suites (TLS_AES_256_GCM_SHA384), x25519 elliptic curve key exchanges, and full session reassembly confidentiality.

4. Strategic Defense-in-Depth Roadmap

  • Phase 1 (Immediate P0): Enforce parameterized queries across all database transactions; mandate JWT role-check decorators on all administrative APIs.
  • Phase 2 (Short-Term P1): Implement CSP, HSTS, and X-Content-Type-Options: nosniff headers at the reverse proxy; restrict CORS origins.
  • Phase 3 (Strategic P2): Integrate automated SAST (Semgrep) and DAST (OWASP ZAP) into the continuous integration / continuous deployment pipeline.
